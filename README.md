# Popoola Toluwani Academic & Professional Services — GitHub Pages

This is the static GitHub Pages version of the website. It has Home, Services, About, Contact, FAQ, Privacy and 404 pages. Enquiries use direct WhatsApp and email links; there is no form backend or stored submission database in this version.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `popoola-toluwani-site`.
2. Upload the contents of this folder to the repository root. Ensure `index.html`, `site.css`, and `404.html` are at the root, not inside another folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
5. Wait for the Pages deployment under **Actions**. GitHub will show the site URL in **Settings → Pages** when it is published. The project-site address will use the form `https://YOUR-USERNAME.github.io/popoola-toluwani-site/`.
6. Open the published HTTPS address and check every page, WhatsApp button, and email button on a phone and a computer.

GitHub Pages is available for public repositories on GitHub Free. The published website is public. Its free hosting address is on `github.io`; a custom domain is optional and must be registered separately. See the [GitHub Pages setup guide](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) and [publishing-source instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Important limits

- GitHub Pages serves static files. It cannot run the WordPress theme, PHP plugin, or database-backed enquiry form.
- The Contact page uses the WhatsApp link and mailto buttons instead. The email button opens the visitor’s configured email app.
- Prices are quote-based. No testimonials, fake client outcomes, personal biography, street address or response-time promise are included.
- Analytics is not installed. Add it only after creating an analytics account and updating the privacy notice and consent flow as needed.

## Update content

Edit the relevant page’s `index.html` file, save, and upload/commit the change to the repository. GitHub Pages republishes changes from the selected branch. Change the brand, email links and WhatsApp link consistently across page headers and footers.
